## 本周必读

- **[Claude API version 2026-10-21 and new major SDK versions](https://platform.claude.com/docs/en/api/migration-2026-10-21)**（Claude API release notes）：发布 API 版本 2026-10-21，各语言 SDK 和 ant CLI 同步出大版本（Python SDK 2.0.0、TypeScript SDK 1.0.0 等）并默认使用新版本。SDK 有与 API 版本无关的破坏性改动，许可证从 MIT 改为 Apache 2.0，升级前要看迁移指南。
- **[Donating Agent Skills to the Agentic AI Foundation](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)**（Anthropic News）：Anthropic 把 Agent Skills 开放标准捐给 Linux 基金会旗下的 Agentic AI Foundation，由 Anthropic、Google、OpenAI 等公司的工程师共同维护，已有 70 多个 agent 平台采用。之后会有版本化发布、正式提案流程和面向 skill 作者的安全指南，写的 skill 可以跨平台复用。
- **[Context Engineering Starts with Retrieval](https://www.langchain.com/blog/context-engineering-starts-with-retrieval)**（LangChain Blog）：上下文工程的基础是检索：先 glob/grep 搜索再分页读取，大结果写到文件只返回路径和预览，关键词不够时再加语义检索。推荐「检索、落盘、委派」模式，让子 agent 读文件后只返回关键事实，检索到的文本一律当作不可信数据。
- **[Memory Tax: Dissecting the Net Value of Agent Memory](https://huggingface.co/papers/2610.34073)**（HF Daily Papers）：把 agent 记忆系统的净价值拆成「记忆收益」和「记忆税」，以朴素 RAG 为基线做大规模评测。发现很多专门的记忆系统反而不如直接检索原始历史，因为整理和压缩过程丢掉或模糊了证据，做 agent 记忆前值得先读。
- **[What Effort Level Should I Choose? On the Economics of Reasoning Effort in LLM Agents](https://huggingface.co/papers/2610.34491)**（HF Daily Papers）：测了不同 reasoning effort 档位在单次推理和长时程 agent 任务上的效果与成本：高档位常在低档位能解的题上失败，简单题成本最高可差 42 倍。从最低档开始、验证失败后再升档的策略，效果持平或更好且更省钱。
